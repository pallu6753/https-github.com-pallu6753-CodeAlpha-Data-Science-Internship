## Task 1: Iris Flower Classification

**Developer:** Pallavi R

About the Task:
In this task, a machine learning model was built to classify iris flowers into different species based on their physical features such as sepal length, sepal width, petal length, and petal width.

What Was Done:

* Loaded the Iris dataset
* Explored and understood the dataset
* Split the data into training and testing sets
* Trained a classification model
* Evaluated the model performance

Outcome:
The model was able to classify iris flower species with high accuracy.

File:
iris_flower_classification.ipynb

## Task 3: Car Price Prediction

**Developer:** Pallavi R

About the Task:
This task focused on predicting the selling price of cars using various features such as year, fuel type, transmission type, and present price.

What Was Done:

* Cleaned and prepared the dataset
* Encoded categorical variables
* Split the data into training and testing sets
* Trained a Linear Regression model
* Evaluated the model using regression metrics

Result:

* The model achieved an R² score of approximately 0.85, indicating good predictive performance

File:
car_price_prediction.ipynb
